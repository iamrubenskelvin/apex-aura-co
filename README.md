# RVGL Suplementos 

A ideia é criar um briefing extremamente detalhado, inspirado na qualidade da Soldiers Nutrition, mas com uma identidade própria, evitando copiar elementos protegidos da marca. Quanto mais específico for o briefing, melhores tendem a ser os resultados em ferramentas como Lovable, Bolt ou v0.

PARTE 1 — IDENTIDADE DO PROJETO E DIRETRIZES GERAIS



PROJETO

Desenvolva um e-commerce premium especializado na venda de suplementos alimentares. O objetivo é criar uma plataforma moderna, sofisticada, extremamente rápida e com foco total em conversão.

O site não deve parecer um template genérico. Ele deve transmitir profissionalismo, confiança e autoridade desde o primeiro acesso.

O visitante deve sentir que está comprando em uma das maiores lojas de suplementos do Brasil.

Toda a experiência deve ser construída pensando em velocidade, simplicidade, organização e credibilidade.

O design deve seguir o padrão visual das maiores lojas internacionais de suplementos, porém com identidade própria.

Jamais utilizar elementos visuais copiados de outras marcas.



PERSONALIDADE DA MARCA

A marca transmite:

Performance

Força

Evolução

Saúde

Alta qualidade

Tecnologia

Confiança

Resultado

Exclusividade

A comunicação deve ser objetiva.

Pouco texto.

Muito impacto visual.



OBJETIVO DO SITE

O principal objetivo do site é vender.

Todas as decisões de design devem aumentar a taxa de conversão.

O usuário nunca deve ficar perdido.

Em qualquer página deve existir um caminho claro para comprar.

ESPAÇAMENTO

O layout deve respirar.

Nunca deixar componentes muito próximos.

Padding generoso.

Margens consistentes.

Grid perfeitamente alinhado.



RESPONSIVIDADE

O site deve ser Mobile First.

Funcionar perfeitamente em:

iPhone

Android

Tablet

Notebook

Ultrawide

TV

Não apenas adaptar.

Cada versão deve parecer desenhada especificamente para aquele dispositivo.



EXPERIÊNCIA DO USUÁRIO

Toda navegação deve ser extremamente intuitiva.

O usuário nunca deve pensar onde clicar.

Tudo deve ser natural.

Os elementos mais importantes precisam chamar atenção primeiro.

A compra deve acontecer com o menor número possível de cliques.



MICROANIMAÇÕES

Todos os elementos interativos possuem animações.

Exemplos:

Botões

Cards

Ícones

Favoritos

Carrinho

Pesquisa

Categorias

Scroll

Tudo deve parecer vivo.

Sem exageros.



LOADING

Nunca utilizar telas de carregamento simples.

Criar Skeleton Loading.

Os produtos aparecem gradualmente.

As imagens carregam com efeito Fade.



PERFORMANCE

O site deve atingir pontuação máxima no Lighthouse.

Carregamento inferior a 2 segundos.

Imagens otimizadas.

Lazy Loading.

Code Splitting.

Compressão automática.

SEO otimizado.



ACESSIBILIDADE

Contraste adequado.

Navegação por teclado.

Leitores de tela.

Alt em todas as imagens.

Foco visível.

Textos legíveis.

Todo componente deve parecer premium.

Nenhuma tela pode parecer inacabada.
